# Find-First-ff
A JavaScript function that combines similar functionality from head and grep functions.
It takes three parameters: a file name, a word or pattern to look for, and the number of lines to scan. It reads the contents of the files, converts it into a string, then splits each line, creating a searchable array of strings. The function then iterates over the array n number of lines to search for the word or pattern (e.g. search for "ERROR" in a log file). If it finds the word or pattern within n number of lines, it will print the line in which the instance of the word or pattern appears. This tool runs using node.js with the following usage: node ff.js [pattern] [file name] [number_of_lines]

AI-Assistance used:
To test this tool, I utilized Microsoft Copilot in order to generate test files to test the functionality of the tool. I also asked it to check my code for any edge cases, and it did identify an edge case in which n number of lines was larger than the length of the file. An appropriate fix was provided by the tool and was implemented into the code. For testing error handling when an incorrect usage syntax was used, or a NaN value was provided as n number of lines, manual testing was completed with my own test cases.
